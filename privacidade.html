Política de Privacidade

Última actualização: Junho de 2026

1. Responsável pelo Tratamento

Tours Lisboa, operado em nome individual, com actividade de transporte turístico privado na região de Lisboa. Contacto: disponível através do formulário em duetoextra.pt ou pelo WhatsApp (+351 912 688 078).

2. Dados Pessoais Recolhidos

Recolhemos os seguintes dados através do formulário de contacto:

  • Nome completo
  • Endereço de email
  • Número de telemóvel (com indicativo internacional)
  • País de origem
  • Conteúdo da mensagem

Adicionalmente, com o seu consentimento expresso, o Meta Pixel (Facebook) pode recolher dados de comportamento de navegação para fins analíticos e publicitários.

3. Finalidade do Tratamento

Os dados do formulário são utilizados exclusivamente para responder ao pedido de contacto ou reserva de tour. Não utilizamos os dados para qualquer outra finalidade comercial.

4. Cookies e Rastreio Analítico

Este site utiliza o Meta Pixel (Facebook) para análise de tráfego e optimização de publicidade digital. Este cookie só é activado após o seu consentimento expresso, através do banner que aparece na primeira visita. Pode revogar o consentimento a qualquer momento limpando os dados do browser (localStorage) ou contactando-nos.

Utilizamos também localStorage para guardar as suas preferências de idioma e de consentimento de cookies — estes dados não são enviados para servidores externos.

5. Partilha de Dados com Terceiros

Os dados do formulário são processados pelo serviço Formspree (formspree.io), que os encaminha por email para o responsável do serviço. Consulte a política de privacidade do Formspree.

Com o seu consentimento, dados de navegação são partilhados com a Meta Platforms, Inc. (Facebook/Instagram) através do Meta Pixel. Consulte a política de privacidade da Meta.

Não vendemos nem cedemos dados pessoais a terceiros para fins comerciais.

6. Os Seus Direitos (RGPD)

Nos termos do Regulamento Geral de Protecção de Dados (RGPD — Regulamento UE 2016/679), tem direito a:

  • Acesso — saber que dados temos sobre si
  • Rectificação — corrigir dados incorrectos
  • Eliminação — solicitar a remoção dos seus dados
  • Oposição — opor-se ao tratamento para fins de marketing
  • Portabilidade — receber os seus dados num formato legível por máquina

Para exercer estes direitos, contacte-nos através do formulário em duetoextra.pt ou pelo WhatsApp (+351 912 688 078).

7. Retenção de Dados

Os dados de contacto são retidos apenas pelo tempo necessário para responder ao pedido (geralmente até 12 meses). Pode solicitar a eliminação antecipada a qualquer momento.

8. Segurança

Este site utiliza HTTPS (TLS) para encriptar todas as comunicações. O formulário é processado por serviços externos com as suas próprias medidas de segurança.

9. Alterações a esta Política

Podemos actualizar esta política ocasionalmente. A data da última actualização está indicada no topo desta página.
